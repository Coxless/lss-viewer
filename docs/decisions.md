# 判断の記録

## 2026-11-01：ビューアは Firefly を拡張せず自作する

**決定：** `web/` に WebGL2 のビューアを自作する。

**調べたもの：** Firefly の `main`（2026-10-30 時点）のコード。

| 観点 | Firefly | zspace の要件 | 評価 |
|---|---|---|---|
| ライセンス | AGPL-3.0 | 静的配信のデモ。組み込みの条件を増やしたくない | 拡張すると zspace 全体に AGPL が及ぶ |
| 依存の大きさ | `static/lib` だけで 2.6 MB（three.js、d3、jQuery、socket.io など） | 初回のデータ転送 1 MB 以下、小さいバンドル | 目標に合わない |
| 描画 | three.js 上で点を描く | 点・メッシュ・線だけの生 WebGL2 | concept 7.1 と逆 |
| データの準備 | Python で前処理、独自の八分木形式 | Rust コアの共通化（CLI と Wasm） | U5 と U9 を別に作ることになる |
| 不足機能 | ボイド輪郭の重ね表示、スライスの板、飛び込み、しきい値の即時変更 | すべて必須 | 既存の UI（約 1,800 行の構築コード）への追加が必要 |

**理由：** どの観点でも、追加で作る量が減らない。プロトタイプで操作感と描画は確認済みで、移植の見通しが立っている。AGPL の影響だけでも採用しない理由として十分。

**評価の範囲：** コードとライセンスの読解まで。性能は実測していない。

## 2026-11-01：転送と圧縮

**決定：** 部分取得は `points.bin` のみ。`shells` と `density` は `.bin.gz` で丸ごと取得し、Worker の `DecompressionStream` で展開する。

**理由：** ホストの圧縮設定に依存しないため。GitHub Pages は HTML への `Accept-Encoding: gzip` 付き Range に、圧縮後のバイト範囲を返した。

## 2026-11-01：模擬カタログは再実装

**決定：** Rust で再実装し、プロトタイプの Wasm 出力と統計で比較する（`fixtures/tools/compare-mock.mjs`）。

**理由：** プロトタイプの C ソースは現存しない。バイト一致は求めず、観測範囲、種別の比率、δ の分布、メッシュの規模を合わせる。

## 2026-11-01：公開前の確認（調査結果。法的助言ではない）

**SDSS データ：** 再配布の障害は見つからなかった。SDSS の [Image Use Policy](https://www.sdss.org/collaboration/image-use-policy/) に「All SDSS data released in our public data releases are considered in the public domain.」とある。ただし画像利用のページの記述で、DR18 のページには利用条件の記載がない。

- ビューアは `sdss.org` へのリンク付きでクレジットを表示している。画像の Web 利用について SDSS がお願いしているリンクと同じ形で、データについての要件ではない
- SDSS が定めた謝辞は論文向けで、Web ツール向けの定めは見つからなかった
- 明確なライセンス文書が必要なら、SDSS に問い合わせる

**VAST カタログ：** CC-BY-4.0。クレジットは表示済み。

**「zspace」の名前：** 公開前に判断が必要。リスクは低くない。

- zSpace, Inc. は Nasdaq 上場の現存企業で、教育向け AR/VR 製品を販売している
- [Justia の記録](https://trademark.justia.com/owners/zspace-inc-2595031)では ZSPACE（serial 77382592）を所有し、対象は 2D・3D の投影画像のためのソフトウェアとハードウェア。zspace（3D 表示ソフトウェア、教育的な用途）と分野が近い
- 登録の現状と日本での出願は未確認。USPTO と J-PlatPat での確認、または専門家への相談が必要

**推奨：** 名前を変えるなら公開前が最も安い。名前が出る場所は少ない（画面の見出し、README、クレート名、CLI 名）。

**決定（2026-11-01）：** 名前は `zspace` のまま、ライセンスは MIT とする（利用者の判断）。実行時の依存はすべて MIT と両立するライセンスであることを確認した。README に zSpace, Inc. とは無関係である旨を記載した。
