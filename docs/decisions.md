# 判断の記録

## 2026-11-01：ビューアは Firefly を拡張せず自作する

**決定：** `web/` に WebGL2 のビューアを自作する。

**調べたもの：** Firefly の `main`（2026-10-30 時点）のコード。

| 観点 | Firefly | zspace の要件 | 評価 |
|---|---|---|---|
| ライセンス | AGPL-3.0 | 静的配信のデモ。組み込みの条件を増やしたくない | 拡張すると zspace 全体に AGPL が及ぶ |
| 依存の大きさ | `static/lib` だけで 2.6 MB（three.js、d3、jQuery、socket.io など） | 初回のデータ転送 1 MB 以下、小さいバンドル | 目標に合わない |
| 描画 | three.js 上で点を描く | 点・メッシュ・線だけの生 WebGL2 | concept 7.1 と逆 |
| データの準備 | Python で前処理、独自の八分木形式 | Rust コアの共通化（CLI と Wasm） | U5 と U9 を別に作ることになる |
| 不足機能 | ボイド輪郭の重ね表示、スライスの板、飛び込み、しきい値の即時変更 | すべて必須 | 既存の UI（約 1,800 行の構築コード）への追加が必要 |

**理由：** どの観点でも、追加で作る量が減らない。プロトタイプで操作感と描画は確認済みで、移植の見通しが立っている。AGPL の影響だけでも採用しない理由として十分。

**評価の範囲：** コードとライセンスの読解まで。性能は実測していない。

## 2026-11-01：転送と圧縮

**決定：** 部分取得は `points.bin` のみ。`shells` と `density` は `.bin.gz` で丸ごと取得し、Worker の `DecompressionStream` で展開する。

**理由：** ホストの圧縮設定に依存しないため。GitHub Pages は HTML への `Accept-Encoding: gzip` 付き Range に、圧縮後のバイト範囲を返した。

## 2026-11-01：模擬カタログは再実装

**決定：** Rust で再実装し、プロトタイプの Wasm 出力と統計で比較する（`fixtures/tools/compare-mock.mjs`）。

**理由：** プロトタイプの C ソースは現存しない。バイト一致は求めず、観測範囲、種別の比率、δ の分布、メッシュの規模を合わせる。
